# Script Video Demo - ZED-ZEN Media Converter

## Setări OBS Recomandate

### Video
- **Rezoluție**: 1920x1080 (Full HD)
- **FPS**: 30 (suficient pentru demo software)
- **Encoder**: x264 sau NVENC (dacă ai GPU NVIDIA)
- **Bitrate**: 6000-8000 kbps

### Audio
- **Microfon**: Apropiat de gură, fără ecou
- **Sample Rate**: 48kHz
- **Bitrate**: 160 kbps

### Sfaturi OBS
1. Folosește "Display Capture" sau "Window Capture"
2. Ascunde bara de taskbar (arată mai profesionist)
3. Închide toate notificările (Focus Assist ON)
4. Mărește cursorul mouse-ului (Setări Windows > Accessibility > Mouse pointer)
